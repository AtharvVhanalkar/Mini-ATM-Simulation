# Mini-ATM-Simulation
A beginner Java console application that simulates an ATM with balance checking, deposits, and withdrawals using loops and conditional statements.
# 🏧 Mini ATM Simulator

A simple console-based ATM application built in Java to practice programming fundamentals.

## Features

- 💰 Check account balance
- ➕ Deposit money
- ➖ Withdraw money
- ⚠️ Insufficient balance detection
- 🔁 Menu-driven interface using loops
- ⌨️ User input with Scanner

## Concepts Used

- Java
- Variables
- Scanner
- if / else if / else
- Nested if statements
- while loops
- Arithmetic operations

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or VS Code.
3. Run `Main.java`.
4. Follow the on-screen instructions.
